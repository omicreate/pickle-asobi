# ピクルくんとあそぼ

**Play with Pikuru** — pickleball party games for one phone or tablet.
Put the device on a table and two players play face to face, or play solo against Pikuru. Each player picks their own level (little kids → competitive players), so kids and adults can play together.

- **Play:** https://omicreate.github.io/pickle-asobi/?lang=en (free, no install, works offline)
- **Languages:** English / Japanese (follows your device; switch with 🌐)
- **Stack:** React + TypeScript + Vite, PWA. Tests run on every push before deploying to GitHub Pages.
- **Privacy:** records stay on your device. Only anonymous play counts are sent, never with Do Not Track / GPC on, and parents can turn them off.

*The rest of this README is in Japanese.*

---

スマホやタブレット1台で遊ぶピックルボールのミニゲーム集。遊び方は3つ：**むかいあう**（机に置いて2人で上下から同時に）、**ひとりで**、**てわたし**（1台を順番に回す。にせピクルくん・ジェスチャー・いしんでんしん・じゅんばんモード）。ゲームによっては遊び方を選べる。
子ども同士・親子・選手同士で遊べるよう、**レベルは1人ずつ選ぶ**（ちびっこ／キッズ／おとな／せんしゅ）。
アプリストアには出さず、Web ページを「ホーム画面に追加」して使う（PWA・オフライン可）。
画面は**日本語と英語**（端末のことばで決まる。ホームの 🌐 か おうちの方へ で切りかえ。`?lang=en`）。

- 公開先：https://omicreate.github.io/pickle-asobi/ （`main` に push すると、GitHub Actions がテストを通してから公開する）
- 大人向けの「ピックルボールIQ」アプリとは別。共通なのはピクルくんと色だけ

## ミッション・きせかえ・共有・集計

- **きょうのミッション**：日付から毎日3つ決まる（かんたん／きろく／いっしょに）。1つ達成で ⭐1、3つ全部で ⭐+2。遊んだ日はスタンプになる（`src/core/missions.ts`・`progress.ts`）
- **きせかえ**：⭐と交換して、ピクルくんの小物（公式の絵の上に重ねる。形・色は変えない）と、パドルの色・もよう・かたちを集める。かたちは公式ルールの大きさの中の本物の形（PBK-0044）。見た目だけで強さは変わらない。とくべつな物はスタンプ7こ・14こ、ミッション10こ、じゅんばんモードで もらえる（`src/core/items.ts`・`src/ui/accessories.ts`）
- **きねんカード**：結果画面の 📸 から、名前の入らない画像（1080×1080）を作って端末の共有画面で送る。作る前に保護者の確認（かけ算）を出す。共有の文のリンクは、そのゲームの準備画面を開く。ひとりの記録には「この きろくに ちょうせんしてね」をそえる（`src/ui/ShareSheet.tsx`・`shareCard.ts`）
- **じこベストと メダル**：ひとりで遊ぶゲーム（と ディンク）の 9本に、どう・ぎん・きん の目標。メダルで ⭐（どう・ぎん1、きん2）。メダル9こ（どう1・ぎん2・きん3で数える）で「チャンピオン」のパドル。じゅんばんモードの記録は数えない（`src/core/records.ts`、画面は `#/records`）
- **ホーム**：カードごとにゲームの絵（字が読めない子でも見分けられるように。`src/ui/GameIcon.tsx`）、「また あそぶ」（さいきん始めた3本）、じこベスト
- **遊びすぎの声かけ**：続けて遊んだ時間が決めた時間（おうちの方へ で なし・20・30・45分。はじめは30分）をこえると、結果が出たときに「ちょっと きゅうけい しよう」。ゲームの途中では止めない。10分はなれたら数え直す（`src/core/playtime.ts`）
- **遊ばれた回数の集計（匿名）**：公開版でだけ、できごと（開いた・始めた・最後まで遊んだ・共有した）とゲーム名、リンクの印（`?src=`）、ホーム画面から開いたか、アプリの版を送る。最後まで遊んだときは、レベル（`lv`）・遊んだ秒数（`sec`）・記録（`val`。ふたりのゲームは レベルの低い方が勝ったら1）も送る（0.15.1 から。難しさの調整に使う。集計シート「あそぼ_レベル別」）。名前・写真・端末ID・Cookie・位置は送らない。ことばの設定は送らない。送り先は `site.config.json` の `counterUrl`（Google Apps Script の受け口。ソフトテニスIQと同じしくみで、スプレッドシート「pickleball_iq_数値集計」に書く。受け口の正本は別リポジトリ `pbiq-metrics`）。ビルド時に CSP の connect-src に足される。おうちの方へ で止められる。DNT・GPC がオンなら送らない。`?src=` は読んだらアドレスから消す（`src/core/counter.ts`）
- **リンクの印**：Instagram のプロフィール `?src=pb_ig_bio`、Threads `?src=pb_th_bio`、ソフトテニスIQから `?src=pb_st_cross`、きねんカード `?src=share`（そのゲームの準備画面に直接入る）
- **おうちの方へ**（`#/parents`、保護者の確認つき）：この端末の記録（ゲームごとの回数）・集計の説明とオンオフ・アプリの紹介・記録を消す

ルールの根拠は USA Pickleball 公式ルールブック 2026 と、それを項目ごとに整理した知識カード（PBK）。問題や判定のコードに PBK 番号を書いてある。

## ことば（日本語・英語）

- しくみ（`src/i18n/`）：画面の文は**日本語の文そのものを鍵**にして `t('…')` で包み、英語の表（`src/i18n/en/*.ts`）から引く。表に無い文は日本語のまま出る。数などは `t('{0}てん', [n])` のように入れる
- ことばは開いたときに1回だけ決める：`?lang=en|ja`（覚えてアドレスから消す）→ 覚えている設定 → 端末のことば（日本語でなければ英語）。切りかえるとページを読みなおす
- 太字が文の途中にある文は `**…**` を入れて1つの文のまま訳し、`<Rich text={t('…')} />` で出す（ことばで太字の位置が変わるため）
- 英語の表：データの文（ゲーム名・あそびかた・問題・お題・ミッションなど）は `node scripts/i18n-dump.mjs <group>` で並べて訳し、画面の文は `src/i18n/en/ui.ts`。もれは `node scripts/i18n-keys.mjs` で探す（テスト `src/i18n/en.test.ts` も、もれ・{0} の数・日本語の残りを確かめる）
- 日本語の文を直したら、英語の表の鍵も直す（テストが落ちて気づける）
- 英語のときの声は ElevenLabs の英語の声（`public/voice/en/`）。mp3 が無い文は端末の読み上げ（en-US）
- 英語の単位：ラリーのルール文は フィート（メートル）

## 使い方

```bash
npm install
npm run dev        # http://localhost:5173/pickle-asobi/
npm test           # ルール・物理・早押し・問題のテスト（Vitest）
npm run test:e2e   # スマホ・タブレットの大きさで2人同時のタッチなど（Playwright）
npm run build      # dist/ に出力（sw.js に事前キャッシュの一覧を埋め込む）
```

実機で試すとき：`npx vite --host` で起動して、同じ Wi-Fi のスマホ・タブレットから `http://<PCのIP>:5173/pickle-asobi/` を開く。

## 声（ElevenLabs）

読み上げの声は ElevenLabs で**前もって** mp3 にして `public/voice/` に置く。遊ぶ最中は通信しない（鍵が外に出ない・オフラインで鳴る）。
mp3 が無いセリフは、端末の読み上げ（speechSynthesis）で読む。

```bash
cp .env.example .env     # ELEVENLABS_API_KEY と ELEVENLABS_VOICE_ID を入れる（.env は git に入れない）
npm run voice:dry        # 作るセリフと文字数を見る（API は呼ばない）
npm run voice            # まだ無いセリフだけ作る
```

セリフの一覧は `src/core/voiceLines.ts`（ゲームの説明・こども向けクイズ・決まり文句）。問題を直すと次の `npm run voice` で声も追いつく。

英語の声は `public/voice/en/`（声は ElevenLabs の公開ライブラリの「Sarah - Fun, Open-minded and Youthful」、`.env` の `ELEVENLABS_VOICE_ID_EN`。モデルは日本語と同じ eleven_v4）。英語の文を直したら：

```bash
npm run voice:en:dry     # 英語で作るセリフと文字数
npm run voice:en         # まだ無い英語のセリフだけ作る
```

声は ことばごとに保存する：Service Worker は声を最初の一覧（事前キャッシュ）に入れず、アプリが開いたときに知らせる いまのことば（`{ type: 'voices', lang }`）の声だけを入れる。英語の人が日本語の声を、日本語の人が英語の声をダウンロードしない（`scripts/build-sw.mjs`・`public/sw.js`）。

## 画像

`art/` のピクルくんの原画から、表情4つとアイコンを作る：`npm run art`

## 方針

- 子ども向けなので、外部に送るのは匿名の回数だけ（公開版・保護者が止められる）。記録・ほし・きせかえは端末の中だけ。子どもだけで SNS に送れないよう、共有の前に保護者の確認を出す
- 画面は「縦長の舞台」を基準に作り、横向きなら 90° 回す。上の人の文字は 180° 回す（`src/core/Stage.tsx`）
- 物理・ルール・早押しの判定は React に依存しない純粋な関数にして、テストで確かめる
- パドルの「スタンダード」はピクルくんの原画と同じ形（オレンジの面・内側の明るい縁・緑の輪郭・握り）で、比率は本物どおり（面28cm×20cm・握り13cm）。どのゲームでもつぶしたりのばしたりしない（`src/ui/paddleArt.ts`）。ラリーの当たり判定（とどく範囲）はうすい帯で見せる
- ピクルくんは原画から背景を抜いた絵（`public/pikuru/cut-*.png`、`npm run art` で作る）で、審判・対戦相手・ボールマシンの係・応援・合図・出題・走る姿として出す（`src/ui/pikuruArt.tsx`）

```bash
npm run dev -- --port 5180          # 開発サーバー（別のターミナルで）
node scripts/promo/shots.mjs        # 画面を撮る（スマホ 390×844 を3倍・日本語と英語）
node scripts/promo/build.mjs        # リール（縦 1080×1920・ナレーションつき）と画像3枚（1080×1350）。ja / en だけも可
```

台本は `scripts/promo/scenes.mjs`（説明はアプリに合わせる。ゲームの数と読みは `src/shell/games.ts` から数える）。ナレーションは ElevenLabs（日本語 いろはうた・英語 Sarah、速さ1.1）で、`out/promo/voice/` にためて二度課金しない。数字の読みがかすれることがあるので、作ったら文字起こしで確かめる（例：「にじゅう さんぼん」と区切る）。
